# Default Skin Assets

Place your default skin assets here:

- `avatar-proxy.png` - Proxy avatar (64x64 recommended)
- `avatar-minion.png` - Minion/Coder avatar (64x64 recommended)
- `avatar-scout.png` - Scout/Researcher avatar (64x64 recommended)
- `avatar-sage.png` - Sage/Strategist avatar (64x64 recommended)
- `sprite-minion.png` - Minion sprite sheet for Phaser (optional)
- `sprite-scout.png` - Scout sprite sheet for Phaser (optional)
- `sprite-sage.png` - Sage sprite sheet for Phaser (optional)
- `sprite-proxy.png` - Proxy sprite sheet for Phaser (optional)

For now, the app will use placeholder rectangles. Replace these with your actual pixel art assets.
